# 📱 أَثَر — تطبيق الأندرويد والموبايل (React Native & Expo)

نسخة الهواتف الذكية الرسمية من **منصة أَثَر الإسلامية** مبنية بأحدث تقنيات React Native و Expo مع دعم كامل للغة العربية والاتجاه من اليمين لليسار (RTL).

---

## 🌟 المميزات الرئيسية للتطبيق:

1. 📖 **المصحف الشريف**:
   - تصفح السور الـ ١١٤ بالرسم العثماني.
   - الاستماع لآيات القرآن الكريم بصوت **١٧ قارئاً من كبار قراء العالم الإسلامي**.
   - التفسير الميسر لكل آية عبر نافذة منبثقة سريعة.
   - حفظ موضع القراءة الأخير تلقائياً (Bookmark).

2. 📻 **الإذاعات الإسلامية (بث مباشر)**:
   - إذاعة القرآن الكريم من القاهرة.
   - إذاعة السنة النبوية الشريفة.
   - إذاعات كبار القراء (المنشاوي، الحصري، عبد الباسط، العفاسي، المعيقلي، وغيرهم).
   - مشغل صوتي يدعم **العمل في الخلفية وقفل الشاشة** (Background Playback).

3. 📿 **الأذكار والسبحة الإلكترونية**:
   - أذكار الصباح والمساء، أذكار الصلاة، أذكار النوم والاستيقاظ.
   - سبحة إلكترونية ذكية مع **اهتزاز لمسي تفاعلي (Haptic Feedback)** عند كل تسبيحة وتنبيه باكتمال الورد.

4. 📚 **المكتبة الإسلامية والشروحات**:
   - أمهات كتب التراث (رياض الصالحين، تفسير ابن كثير، العقيدة الواسطية، سيرة ابن هشام، زاد المعاد، إلخ).
   - سلاسل الشروحات الصوتية العلمية لكبار العلماء.

5. ⏰ **مواقيت الصلاة**:
   - عرض الصلوات الخمس مع وقت الشروق بتوقيت دقيق.

6. 🔍 **البحث الشامل**:
   - محرك بحث فوري في جميع آيات القرآن الكريم الـ ٦٢٣٦.

7. 🌙 **الوضع الليلي والنهاري (Dark / Light Theme)**:
   - تصميم فخم ومريح للعين يطابق هوية موقع أَثَر 100%.

---

## 🚀 كيفية تشغيل التطبيق على الهاتف (Local Development):

### ١. تثبيت الحزم (إذا لزم):
```bash
cd athar-mobile
npm install
```

### ٢. تشغيل بيئة Expo:
```bash
npm start
# أو
npx expo start -c
```

### ٣. المعاينة الفورية على هاتفك:
1. حمّل تطبيق **Expo Go** من متجر Google Play على هاتفك الأندرويد.
2. امسح رمز الـ **QR Code** الظاهر في التيرمينال لفتح التطبيق فورياً على هاتفك.

---

## 📦 استخراج ملف الـ APK النهائي (Android Build):

لبناء ملف APK جاهز للتثبيت على أي هاتف:
```bash
npm install -g eas-cli
eas login
eas build -p android --profile preview
```
